# 易加 eplus UI 设计规范

面向易加 Web 管理端的设计规范，含颜色、字体、图标、按钮、表单、表格、布局和反馈的可交互示例。

## 本地查看

下载仓库后，直接用浏览器打开 `index.html`。页面已内嵌组件和图标，无需安装依赖。

## 在线访问

https://z91668120-oss.github.io/eplus-ui-guide/

通过 GitHub Pages 发布，采用 `main` 分支和仓库根目录。

## 更新

更新 `index.html` 并推送到发布分支。文档中的资料差异和待确认内容统一列在末尾。

示例在浏览器本地运行，不连接业务系统。内嵌开源运行库保留原许可信息。
